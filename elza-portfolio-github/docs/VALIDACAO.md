# Validação do pacote

Preparado em 26/10/2026, a partir da revisão `0b7430d808a6f0f6b2764b6f77e0685ad90f39d0` do portfólio.

- Os arquivos públicos foram copiados integralmente; suas somas SHA-256 foram comparadas com a origem.
- Os 24 testes JavaScript são executados no pacote exportado por `npm test`.
- Referências locais de HTML, CSS e módulos são conferidas antes de compactar.
- O ZIP inclui o workflow de Pages, as capas atuais, o favicon, os módulos 3D e as licenças.
- O workflow foi conferido com as versões documentadas de checkout, setup-node e Pages; a execução em uma conta GitHub só acontece após o envio ao repositório e habilitação do Pages.
- A prévia desktop dos projetos e das capas foi conferida durante a atualização do portfólio. Testes de estado não substituem inspeção visual em todos os dispositivos.

Não são incluídos credenciais, `.git`, arquivos de sessão ou a configuração da hospedagem privada. Não foi criado nem alterado um repositório externo para entregar este ZIP.
